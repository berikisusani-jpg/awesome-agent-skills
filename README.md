# Project FRIDAY - The Ultimate AI Assistant

FRIDAY (Fully Responsive Intelligent Digital Assistant Youth) is a self-evolving, proactive AI ecosystem.

## Real vs. Placeholder Status
- **Brain**: REAL (Claude/Gemini fusion with full tool-calling support).
- **Agents**: REAL (Async architecture, multi-file code generation).
- **Vision**: REAL (Face detection, real-time frame analysis).
- **Integrations**: REAL (Gmail, Calendar, Spotify, Weather, Smart Home) - wired to actual SDKs.
- **Security**: REAL (Path allow-listing, API Bearer authentication, PC Control audit logs).

## Setup
1. `python setup.py`
2. Edit `.env` (Set `FRIDAY_API_TOKEN` for security).
3. `python main.py`
